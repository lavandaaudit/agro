# 🌾 AGRO.MAGAZ | Агроринок, Live 24h Парсери, Точне Господарство та Інтернет-Магазин Тракторів

**AGRO.MAGAZ** — сучасний інтелектуальний агрохаб, який об'єднує живий моніторинг світового та українського агроринку в режимі реального часу, аналітику точного землеробства та повноцінний інтернет-магазин сільгосптехніки Case IH.

---

## 🌟 Основні можливості платформи

### 1. 🇺🇦 Жива стрічка новин Агро Україна (24 години)
- Парсинг новин виключно за останні 24 години з провідних галузевих джерел (*Latifundist.com, AgroPortal.ua, Суспільне Новини, Укрінформ, Elevatorist, АПК-Інформ*).
- Автоматичний розрахунок часу публікації (*"15 хв тому", "2 год тому"*).
- Категоризація матеріалів: **Експорт та Логістика, Ціни та Ринок, Виробництво та Поля, Фінанси та Держпідтримка, Агротех**.
- Прямі безпечні посилання на першоджерела.

### 2. 🌐 Global Agro News (EN, 24h — Без заглушок)
- Повна відсутність заглушок і фіктивних мок-текстів.
- 100% реальні англомовні новини за останні 24 години (*DTN Progressive Farmer, Reuters Ag, Bioengineer, The Indian Express, AgTech Wire, Sierra Sun Times*).
- Окремий фільтр за темами: **Markets, Crops, Trade**.

### 3. 📈 Бігучий рядок (Ticker) та аналітика без симуляцій
- **Офіційний курс НБУ**: пряме підключення до API Національного банку України (`USD`, `EUR`, `PLN`) в режимі реального часу без сторонніх проксі.
- **Пальне в Україні**: верифіковані середні ціни на дизельне пальне (ДП), бензин А-95 та автогаз (LPG).
- **Зернові та олійні культури**: котирування Пшениці 2/3 кл (СРТ Одеса / Дунай), Кукурудзи (СРТ), Соняшнику (СРТ МЕЗ), Сої та Ріпаку.
- **Світові біржі**: котирування CBOT (Wheat, Corn, Soybeans), Matif (Rapeseed) та нафти Brent.
- **Жодних `Math.random()`**: всі коливання та котирування базуються на реальних ринкових фактах.

### 4. 🛰️ Точне господарство (Precision Farming & Agronomic Hub)
- **Інтерактивна карта областей України (Leaflet)**: вибір будь-якого регіону або режим "Вся Україна" з плавним переміщенням.
- **Польові датчики відкритого метео-сервісу Open-Meteo**:
  - Температура повітря та ґрунту на 4 глибинах (поверхня, 6 см, 18 см, 54 см).
  - Пошарова вологість ґрунту (0-1 см, 1-3 см, 3-9 см, 9-27 см, 27-81 см).
  - Евапотранспірація (ET0), дефіцит тиску водяної пари (VPD), точка роси, сонячна радіація.
- **Агрономічні рішення AI**:
  - **Вікно внесення ЗЗР**: автоматичний розрахунок ризику знесення крапель за швидкістю вітру та температурою.
  - **Термічний стан ґрунту**: індикатор готовності до сівби (поріг > 8.5°C на глибині 6 см).
  - **Вологозабезпеченість**: діагностика дефіциту вологи в посівному шарі.
- **Графіки та аналітика (Chart.js)**:
  - 7-денний тренд кореляції температури повітря та ґрунту.
  - Вертикальний профіль вологості ґрунту за глибинами.
  - Радар польових агро-ризиків (посуха, мороз, вітрова ерозія, шкідники, перезволоження).
- **Супутниковий NDVI**: візуалізація вегетаційного індексу з шкалою біомаси.

### 5. 🚜 АгроМагаз — Інтернет-магазин тракторів (Всі машини акуратно знизу)
- Розділ розміщено в нижній частині сторінки на всю ширину як повноцінний електронний шоурум.
- **Модельний ряд**:
  1. **Steiger Quadtrac 715** (778 к.с., гусеничний флагман)
  2. **Magnum 400 CVXDrive** (435 к.с., безступенева трансмісія)
  3. **Optum 440 AFS Connect** (440 к.с., універсал високої потужності)
  4. **Puma 260 CVXDrive** (302 к.с., кабіна Deluxe 66 дБ)
  5. **Axial-Flow 8250** (571 к.с., роторний комбайн Harvest Command)
  6. **Farmall 120C** (117 к.с., фермерський помічник)
- **Конвертація цін за курсом НБУ**: автоматичний перерахунок з доларів США ($) у гривні (₴) на основі живого курсу Нацбанку.
- **Фільтрація за класом**: "Всі машини", "Потужні тягачі 400+ к.с.", "Універсальні 100-300 к.с.", "Збиральна техніка".
- **Інтерактивний лізинговий калькулятор**: вибір авансу від 20% до 60%, строку від 12 до 60 місяців, розрахунок щомісячного внеску в $ та ₴.
- **Модальне вікно замовлення КП**: з автозаповненням обраної машини.

## 🚀 Як запустити проект локально

1. Перейдіть до папки проекту:
```bash
cd /Users/romankatyuschenko/.gemini/antigravity/scratch/agro-magaz
```

2. (Опціонально) Оновіть найсвіжіші 24h новини через скрипт:
```bash
python3 sync_feeds.py
```

3. Запустіть будь-який локальний HTTP-сервер:
```bash
python3 -m http.server 8080
```
або за допомогою Node.js:
```bash
npx serve .
```

4. Відкрийте у браузері:
[http://localhost:8080](http://localhost:8080)

## ⚙️ Автоматичне оновлення даних у production

Для підтримки живої 24-годинної стрічки у режимі 24/7 можна налаштувати запуск `sync_feeds.py` через системний `cron` кожні 15–30 хвилин:

```bash
*/15 * * * * cd /Users/romankatyuschenko/.gemini/antigravity/scratch/agro-magaz && python3 sync_feeds.py >> sync.log 2>&1
```

Або підключити GitHub Actions Workflow з cron-тригером для автоматичного коміту свіжого `data/news_feed.json` у репозиторій.
